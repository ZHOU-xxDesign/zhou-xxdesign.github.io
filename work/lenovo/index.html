联想 · 乐云 LeCloud 3.0

多终端信息共享，打造个人生态圈。这是我职业生涯的第一个项目， 也是在这里学会把设计系统化、理解规范价值的地方。

Time
2021.11 — 2022.07
Role
UI 设计师 · 实习
Scope
多端产品 / 桌面客户端
Output
首页改版 · 托盘方案

Context项目背景

乐云 3.0 的主题是焕新 · 智连 · 极致。 核心要解决的问题是：用户手上有笔记本、平板、手机等多个设备，文件散落各处， 怎么让人在一个客户端里就看清「我的东西都在哪台设备上」。

我负责其中两个模块的改版设计：首页布局重组与托盘方案升级。

01首页布局重组

多终端信息共享，打造个人生态圈。

Change

新增切换设备

把设备切换提到首页显眼位置，加强设备引导交互，让多设备的存在感从「隐藏设置」变成「首页可见」。

Change

显示设备详情

设备卡片直接展示机型、同步范围（文件 / 短信 / 相册 / 联系人 / 通话记录）与同步时间，增强用户使用设备文件时的沉浸感，再次突出设备引导。

改版前，设备信息被折叠在侧栏的图标里；改版后，设备以卡片形态进入主视图， 用户一眼就知道当前有几台设备、各自同步了什么、最后一次同步是什么时候。

02托盘方案升级

强化时间线信息层级，让托盘从「文件列表」变成「最近在做什么」。

01

时间轴引导

按「今天 / 昨天 / 两天前」分组，而不是按文件名排序——按时间轴查看更符合用户找回文件时的心智。

02

直接预览文件

点击文件名即可打开对应文件，减少一次跳转。

03

工具栏

强化个人信息，展示重点功能。

04

打开来源设备

hover 标题区出现设备图标，提供从文件直接进入对应设备的路径——这是把「文件」和「设备」两个心智连起来的关键一步。

视觉上引入了毛玻璃效果，让托盘在桌面上呈现悬浮层级， 而不是一块贴在桌面上的实色面板。

03设备展示

登陆联想账号即可同步关联你的不同设备，实现设备间的切换， 最多可展示 9 个设备。每张设备卡片标注机型与同步状态， 让「我的生态」这件事在界面里是可见、可数的。
